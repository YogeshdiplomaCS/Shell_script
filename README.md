# Shell_script

A collection of shell scripts for learning and automating common Linux/Unix tasks.

## Requirements

- Bash or a compatible shell
- Linux or macOS; Windows users can use WSL or Git Bash

## Get the repository

```bash
git clone https://github.com/YogeshdiplomaCS/Shell_script.git
cd Shell_script
```

## Run a script

Review a script before running it, especially if it changes files or uses system commands. Run a script with Bash:

```bash
bash path/to/script.sh
```

Or make it executable and run it directly:

```bash
chmod u+x path/to/script.sh
./path/to/script.sh
```

Replace `path/to/script.sh` with the actual script path in this repository. Some scripts may need additional permissions or tools; check their comments and prerequisites first. Avoid running scripts with `sudo` unless you understand why it is required.
